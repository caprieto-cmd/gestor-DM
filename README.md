# Compendio de Combate V15 · Sin catálogo SRD básico

- Elimina las 91 entradas SRD 5.1 resumidas incorporadas de fábrica.
- Mantiene la carga del Monster Manual (2014) y otros libros, importación JSON, filtros y selector de versiones.
- Conserva los monstruos personalizados y los encuentros existentes: no se borran datos guardados.
- Los libros importados se restauran desde IndexedDB cuando el navegador conserva su almacenamiento.
- Si abres la app por primera vez sin internet y sin datos importados, el bestiario estará vacío hasta cargar un JSON.
- Para cargar el Monster Manual: Bestiario → selección del libro → Cargar libro.
- Para respaldar tus datos, exporta tus partidas antes de cambiar de versión.

La eliminación del catálogo inicial no significa que se borren los monstruos existentes en tus encuentros.
