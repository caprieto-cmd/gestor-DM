# DM.AID 1.0.0 · Dungeon Master Aid

**Run the game. Rule the story.**

Versión inicial de gestor de iniciativa, personajes, enemigos, NPCs, Objetos y Tiendas para DnD 5e (2014).
Conserva combate, personajes, bestiario, hechizos, PNJ, objetos y tiendas, mantiene almacenamiento de partida actual con posibilidad de exportar en formate JSON.

DM.AID es un proyecto personal no afiliado a Wizards of the Coast.
