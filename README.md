# Compendio de Combate V15 · Paquete completo para GitHub Pages

## Archivos
- `index.html`: aplicación
- `manifest.webmanifest`: configuración de instalación como PWA
- `sw.js`: caché de archivos de la aplicación para uso sin conexión tras abrirla en línea
- `icon-180.png`, `icon-192.png`, `icon-512.png`: iconos

## Publicación
1. Subir los seis archivos anteriores a la raíz del repositorio (README opcional).
2. En GitHub: Settings → Pages → Deploy from a branch → main / (root) → Save.
3. Abrir la dirección de GitHub Pages cuando termine la publicación.

La biblioteca de Monster Manual y otros libros NO está incluida en este ZIP: la carga de libros requiere conexión o importar archivos JSON. La caché de la PWA no guarda automáticamente todos los libros externos; su persistencia depende del almacenamiento local del navegador.

La aplicación mantiene la V15 sin las fichas SRD precargadas. Su código de combate no ha sido alterado.
